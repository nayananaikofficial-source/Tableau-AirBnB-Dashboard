## Project Overview
Interactive AirBnB dashboard built in Tableau Public analysing 
listing prices, availability, and revenue trends.

## Skills Used
- Connecting data sources in Tableau
- Building interactive dashboards
- Charts — bar charts, maps, line graphs
- Filters and parameters
- Data storytelling through visuals

## Key Insights
- Average price by neighbourhood/zipcode
- Revenue trends throughout the year
- Most popular listing types
- Price distribution by bedroom count

## Tools Used
Tableau Public, Excel

## Dataset
AirBnB listings dataset from Alex The Analyst bootcamp
